MARVE Fashion Store — Updated Website

Only these six product categories are included:
1. Indian Traditional Jewellery Set
2. Churi
3. Bra
4. Panty
5. Watch
6. Earrings

Files:
- index.html
- style.css
- script.js
- assets/ (images)

Usage:
1. Extract this ZIP.
2. Keep all three code files and the assets folder together.
3. Open index.html in a browser to preview.
4. Update WHATSAPP_NUMBER in script.js if needed.
5. Change product names and prices in the products array in script.js.

The Jewellery Set, Churi, Bra and Panty use the product images you supplied. Watch and Earrings use sample online images. The order button opens WhatsApp with a pre-filled message. The site can be uploaded to GitHub Pages or Netlify for free hosting.
